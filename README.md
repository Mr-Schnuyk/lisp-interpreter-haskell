# Интерпретатор диалекта языка Lisp

Данный проект представляет собой интерпретатор диалекта языка программирования Lisp, реализованный на языке Haskell с использованием системы сборки Stack.

## Описание проекта

Интерпретатор поддерживает базовые конструкции языка Lisp и выполняет полный цикл обработки исходного кода: от лексического анализа до вычисления выражений.

### Архитектура (папка `src/`)
Проект разделен на логические модули:
* **`Lexer.hs`** — Лексический анализатор (токенизация исходного кода).
* **`Parser.hs`** — Синтаксический анализатор (построение AST).
* **`Semantic.hs`** — Семантический анализ (проверка корректности конструкций).
* **`Types.hs`** — Определение основных типов данных (AST, значения, окружения).
* **`Interpreter.hs`** — Ядро интерпретатора (вычисление выражений).
* **`Utils.hs`** — Вспомогательные утилиты.

### Тестирование (папка `tests/`)
* **`testLex.lsp`** — проверка лексического анализатора.
* **`testStx.lsp `** — проверка синтаксического анализатора.
* **`testSem.lsp`** — проверка семантики.
* **`testRun.lsp `** — проверка выполнения программ.
* **`test1.lsp`** — общие тесты.
* **`supertest/`** — большая комплексная программа на Lisp для финального тестирования интерпретатора.

### Прочее
* **`Промты.hs`** — Файл, содержащий использованные при разработке промты.
* **`KorobovReport.pdf`** — Подробный отчет о проекте.
