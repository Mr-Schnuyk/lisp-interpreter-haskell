Формулировка задачи:
Требуется реализовать вычисление (редукцию) заданного лямбда-выражения, используя
правило бета-редукции и приводя выражение к нормальной форме на основе нормального
порядка редукции.

Общий алгоритм работы: 
Выполняется пошаговое редуцирование на основе НПР:
1) Выбирается редуцируемое лямбда-выражение, согласно НПР
2) При бета-редуцировании выражения: 
- ((λx. lambda-exp1) lambda-exp2) - происходит предварительное альфа-преобразование (при необходимости) выражения lambda-exp1 (если "λx." Є lambda-exp1)
- (λx. (λy. lambda-exp1) lambda-exp2) - также происходит предварительное аналогичное альфа-преобразование lambda-exp1, относительно x
3) Осуществляется текстовая замена x в теле лямбда-выражения на аргумент. При этом шаг 2 гарантирует разрешение коллизий, так что текстовая замена возможна.

Внутреннее представление данных:
Данные представлены в виде вложенного списка лямбда-выражений, где 'λ' := '/', '.' := '>; каждое лямбда-выражение заколючено в скобочки ().
Изначально заданное лямбда-выражение обрабатывается путем текстовых замен.

=================================================
=================================================

Программа получает на вход лямбда-выражение, на выходе - приведенное лямбда-выражение.

Основные функции:
(calculation exprs) - основная функция. Получает на вход исходное лямбда-выражение, запускает пошаговую редукцию (каждый шаг печатается актуальное выражение). Результат - финальное нередуцироемое лямда-выражение.

(normalRstep exprs) - осуществляет шаг НПР: находит редуцируемое подвыражение, вызывает его редукцию.

(redux exprs arg) - осуществляет текстовую замену переменной в заданном выражении на аргумент редуцирования. Предварительно вызывается функция альфа-преобразования заданного выражения.

(alpha exprs var) - осуществляет aльфа-преобразование заданного выражения (поиск нужного альфа-преобразования, вызов функции переименования переменных), отночительно переменной var.

(renaming exprs var) - функция выполняет непосредственное переименование всех переменных var в заданном выражении (для определения нового неконфликтующего имени используется функция getNewName)

(getNewName exprsSet var N) - на основе множества всех имен в заданном выражении с помощью ключа N создается новое имя для переменной var: "var" + "N"

Вспомогательные функции:
(toSet L) - возвращает множество атомов списка L

(connection atom1 atom2) - соединяет 2 атома в новый атом с помощью встроенной функции intern

(eqList L1 L2) - проверяет эквивалентность списков
